# De Patria a Patria

## Descripción del Proyecto

**De Patria a Patria** es un proyecto de desarrollo web responsivo diseñado para ofrecer una interfaz visualmente atractiva, estructurada y optimizada para diferentes resoluciones de pantalla. El propósito principal del proyecto es maquetar una página web fluida que se adapte perfectamente a las necesidades del usuario, garantizando una navegación intuitiva y una jerarquía visual clara de todo el contenido.

## Funcionalidad

- **Diseño totalmente responsivo:** La página se adapta dinámicamente a resoluciones de pantalla críticas (1280px, 768px y 320px) sin romper la estructura ni generar barras de desplazamiento horizontal inesperadas.
- **Estructura semántica:** Uso estricto de etiquetas HTML5 para garantizar la accesibilidad de la interfaz y un correcto indexado.
- **Tipografía adaptable:** Implementación de textos fluidos que se expanden verticalmente sin desbordar los límites de sus bloques contenedores.

## Tecnologías y Técnicas Utilizadas

- **HTML5 Semántico:** Estructuración del contenido utilizando bloques principales como `<header>`, `<main>`, `<section>`, y `<footer>` para mejorar la legibilidad y la accesibilidad.
- **CSS3 Avanzado y Metodología BEM (Flat BEM):** Organización de los estilos en componentes modulares independientes dentro de un directorio `blocks/`, evitando el acoplamiento y asegurando que ninguna regla CSS exceda los dos niveles de anidación.
- **Flexbox y Posicionamiento:** Aplicación de técnicas modernas de CSS para la alineación, distribución y centrado de los bloques y elementos de la página.
- **Media Queries (Consultas de Medios):** Implementación de puntos de ruptura estratégicos para garantizar la adaptabilidad del diseño sin duplicación de estilos innecesaria.
- **Normalización y Fuentes:** Uso de `normalize.css` para homogeneizar el renderizado entre navegadores y de `fonts.css` para integrar la familia tipográfica _Inter_ con fuentes del sistema como alternativa de respaldo.
- **Calidad de Código:** Configuración de entorno mediante `.editorconfig` y `.prettierignore` para asegurar la consistencia del código e indentación de acuerdo con los estándares del validador W3C.
